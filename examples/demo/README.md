# Synthetic demonstration

These fictional studies illustrate eligibility decisions; they are not real research or accuracy evidence. No credentials, browser state, or saved screening records are supplied.

Create a demo project through the menu and use your own accessible demo review address. Paste the sections in criteria.json into its prompt editors, configure an accessible model, and save settings. The studies.json examples are for offline discussion and are not automatically imported into Covidence. Nothing in this directory enables API requests or voting.
